Emergency Cart Restocking Simulation

Practice inventory management and documentation skills by checking expiration dates, identifying medications needing replacement, and generating a charge list report.

Simulation Lab Objectives
In this Simulation Lab, you will:
• Demonstrate how to identify emergency medications and their pharmacology
• Perform tasks associated with replenishing an emergency cart using a charge list
• Document findings for submission
Scenario
You are working in a busy hospital pharmacy and are responsible for restocking the emergency carts. Using your knowledge and data skills, you will replenish each cart using the list provided and document all medications that need replacement.
